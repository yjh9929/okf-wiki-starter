1 · Claude 앱

Code 탭이 안 눌릴 때

증상확인할 것
Code 탭이 안 보임왼쪽 위 탭 줄을 봅니다. 브라우저가 아니라 내려받아 설치한 앱에서만 보입니다. 웹으로 로그인했다면 앱을 설치합니다.
Code 탭이 눌리지 않음앱을 완전히 종료했다가 다시 엽니다. 설치 직후에는 한 번 재시작이 필요한 경우가 있습니다.
요금제를 올리라는 안내가 뜸로그인한 계정이 배포받은 계정이 아닙니다. 로그아웃하고 배포받은 계정으로 다시 로그인합니다.
로그인이 안 됨브라우저 창이 열리며 인증이 진행됩니다. 창이 안 뜨면 팝업 차단을 확인합니다.
배포받은 계정으로 로그인했는데도 요금제 안내가 뜨면 손을 들어 주세요. 계정을 확인해 드리겠습니다.
2 · 폴더 열기

폴더를 못 열 때

증상확인할 것
폴더 선택이 안 됨 (윈도우)Git이 설치되어 있는지 확인합니다. 윈도우는 Git이 있어야 Code 탭이 내 컴퓨터의 폴더를 열 수 있습니다. git-scm.com 에서 받아 기본값으로 설치한 뒤, Claude 앱을 다시 시작합니다.
압축 푼 폴더를 못 찾겠음대개 내려받기(Downloads) 폴더에 그대로 있습니다. 압축을 풀면 okf-wiki-starter 라는 이름으로 폴더가 생깁니다.
폴더를 골랐는데 비어 보임한 겹 더 들어가야 하는 경우가 많습니다. raw 와 wiki 가 바로 보이는 폴더를 골라야 합니다.
입력창이 안 나옴폴더가 열리면 아래쪽에 입력창이 생깁니다. 없으면 폴더 선택이 끝나지 않은 것입니다. 다시 고릅니다.
압축을 아직 안 풀었을 수도 있습니다. ZIP 파일 자체는 폴더로 열리지 않습니다.
3 · Obsidian

보관함이 이상할 때

증상확인할 것
보관함을 잘못 열었음왼쪽 아래 보관함 아이콘 → 다른 보관함 열기 → 폴더를 보관함으로 열기. 새 보관함 만들기가 아닙니다.
빈 보관함이 열림Claude 앱에서 연 폴더와 같은 폴더인지 확인합니다. 둘이 다르면 정리 결과가 보이지 않습니다.
그래프가 비어 있음아직 정리를 안 돌렸으면 정상입니다. 정리를 실행한 뒤에도 비어 있으면 wiki 폴더에 파일이 생겼는지 봅니다.
그래프 화면을 못 찾겠음왼쪽 세로줄의 그래프 아이콘(점과 선 모양)입니다.
4 · 웹 클리퍼

자료가 raw 에 안 담길 때

증상확인할 것
아이콘이 안 보임주소창 오른쪽 퍼즐 조각 아이콘을 누르면 설치된 확장 목록이 나옵니다. 거기서 고정합니다.
저장 위치가 raw 가 아님설정이 두 곳에 나뉘어 있습니다. General → 보관함(Vault), Templates의 Default → 저장 위치(raw). 둘 다 맞춰야 합니다.
저장했는데 파일을 못 찾겠음Obsidian의 raw/ 폴더를 봅니다. 없으면 위의 저장 위치가 비어 있는 것입니다.
본문이 이상하게 잘림로그인이 필요한 페이지나 PDF 뷰어는 잘 안 잡힙니다. 화면을 캡처하거나, PDF는 직접 내려받아 raw/ 에 넣어 주세요.
5 · 정리 실행

정리가 안 돌 때

증상확인할 것
승인 창이 안 뜸아직 읽는 중일 수 있습니다. 1~3분 걸립니다. 그래도 조용하면 같은 문장을 다시 넣습니다.
파일이 안 만들어짐승인을 눌렀는지 확인합니다.
엉뚱한 폴더에 만들어짐Code 탭에서 연 폴더가 실습 폴더가 맞는지 확인합니다.
너무 오래 걸림자료가 많으면 길어집니다. 그동안 Obsidian 그래프를 옆에 띄워 두면 문서가 생기는 것이 보입니다.
도중에 멈춤"이어서 계속해 줘" 라고 넣으면 하던 자리에서 이어 갑니다. 처음부터 다시 하지 않아도 됩니다.
잘못 만들어졌어도 raw/ 는 그대로입니다. "wiki 폴더 비우고 다시 정리해 줘" 로 되돌릴 수 있습니다.
6 · 그래프

그래프에 아무것도 없을 때

증상확인할 것
점이 하나도 없음Obsidian이 실습 폴더를 열고 있는지 확인합니다. 왼쪽 파일 목록에 wiki 가 보여야 합니다.
점은 있는데 선이 없음문서에 wiki/... 링크가 안 들어간 것입니다. "문서끼리 관련 개념으로 이어 줘" 라고 하면 채웁니다.
혼자 떨어진 점이 많음정상입니다. 모듈 ④에서 이어 주는 작업을 합니다.
점이 너무 적음자료가 두세 개면 문서도 몇 개 안 나옵니다. 자료를 더 담고 정리를 다시 실행합니다.
화면이 갱신되지 않으면 그래프 창을 닫았다 다시 엽니다.
