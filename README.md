## 💡 강의 개요

매번 LLM에게 질문할 때마다 긴 문서를 다시 검색하고 계신가요?  
이 워크숍에서는 **Obsidian**과 **Claude Code**, 그리고 **OKF(Open Knowledge Format)**를 활용하여 '공부하고 수집할수록 스스로 연결되고 축적되는 나만의 지식 위키'를 구축하는 방법을 배웁니다.

* 🏢 **Obsidian**: 나만의 생각과 메모가 담기는 **작업실**
* 🧑‍💼 **AI (Claude)**: 자료를 요약하고 정돈해 주는 **사서**
* 📖 **LLM Wiki**: 쌓일수록 지식의 복리 효과를 내는 **나만의 서재**

---

## 🎯 학습 목표

1. **RAG의 한계와 LLM Wiki 이해**: 질문할 때마다 다시 찾는 RAG에는 축적이 없습니다. 미리 정리해 두는 방식이 왜 다른지 이해합니다.
2. **AI 실습 환경 구축**: Claude 데스크톱 앱의 **Code 탭**과 Obsidian, 웹 클리퍼를 내 컴퓨터에 직접 세팅합니다. 터미널은 쓰지 않습니다.
3. **지식 축적의 선순환 체득**: 수집한 자료를 위키 문서로 합성하고, 질문을 통해 정제된 답변을 다시 위키로 저장하는 복리 구조를 경험합니다.
4. **지식 그래프 시각화**: Obsidian Graph View를 읽는 법을 익히고, 연결 안 된 문서와 끊긴 링크를 점검합니다.

## 🛠️ 시작하기

수업 전까지 두 개만 설치해 오시면 됩니다. 용량이 커서 강의실에서 20명이 동시에 받으면 오래 걸리는 것들입니다. 나머지 설정은 전부 수업에서 함께 합니다.

**1. Claude 데스크톱 앱** — <https://claude.com/download>

브라우저 버전이 아니라 컴퓨터에 설치하는 앱이어야 합니다. 설치 후 **배포받은 계정**으로 로그인하고, 앱의 **Code** 탭이 눌리는지만 확인해 주세요.

**2. Obsidian** — <https://obsidian.md>

내려받아 설치하고 **실행**까지만 해보시면 됩니다.

> 💡 일찍 도착하셨다면 위 두 개 중 못 받으신 게 있는지 확인하고 다운로드를 먼저 걸어 두세요.

## 📂 폴더 구조

본 저장소를 내려받으면 아래와 같은 폴더 구조로 구성되어 있습니다.

```text
okf-wiki-starter/
├── 📁 raw/                 # 1. 웹 클리퍼나 파일로 수집한 원본 자료(.md)를 넣는 공간
├── 📁 wiki/                # 2. AI가 OKF 규칙에 맞춰 요약·합성한 개념 문서가 생성되는 공간
├── 📁 .claude/skills/      # 3. AI가 따르는 정리 규칙(okf-wiki 스킬)과 문서 템플릿
├── 📁 docs/                # 4. 강의 교안 슬라이드 (GitHub Pages로 공개)
├── 📄 lint_okf.py          # 위키 점검 도구 (선택 — "위키 점검해 줘"로도 됩니다)
└── 📄 README.md            # 강의 실습 안내서 (현재 문서)
```

## 🔎 수업 뒤에도 이어가기

### 잘 만들어졌는지 확인하기

* Obsidian 그래프에서 개념들이 선으로 이어지는지 봅니다.
* `wiki/` 안에 `index.md`(목차), `log.md`(작업 기록), 그리고 개념 문서들이 생겼는지 봅니다.
* Claude에게 `위키 점검해 줘` 라고 하면 상태를 훑어 줍니다. **끊긴 링크 0건, 연결 안 된 문서 0건**이면 완성입니다.

### 내 주제로 해보기

`raw/`의 예제 대신 내가 관심 있는 자료를 넣어 보세요. 웹 클리퍼로 기사를 담거나, 텍스트를 복사해 `raw/내주제.md` 로 저장한 뒤 `raw 폴더 읽어서 위키로 정리해 줘` 라고 하면 됩니다.

자료가 쌓일수록 문서 수가 아니라 **문서의 밀도**가 올라갑니다. 같은 개념을 다룬 자료를 하나 더 넣어 보시면 새 문서가 생기는 게 아니라 기존 문서에 줄이 늘어나는 걸 보실 수 있습니다.

### 🆘 잘 안 될 때

| 증상 | 이렇게 해보세요 |
| :--- | :--- |
| Code 탭에서 `/okf-wiki` 가 안 보여요 | 연 폴더가 맞는지 확인하세요. 압축을 풀면 같은 이름의 폴더가 한 겹 더 있는 경우가 많습니다 |
| "Git is required" 가 떠요 (Windows) | [Git](https://git-scm.com/downloads/win) 설치 후 Claude 앱을 껐다 켜세요 |
| 파일이 안 만들어져요 | 승인을 물어보는 화면이 떴는지 보세요. 승인 전에는 아무것도 바뀌지 않습니다 |
| 그래프가 비어 있어요 | 아직 "정리해 줘"를 안 돌렸다면 정상입니다 |
| 그래프에 선이 안 보여요 | 문서에 `[[...]]` 연결이 있는지, Obsidian이 Claude와 **같은 폴더**를 열었는지 확인하세요 |

## ❓ FAQ

* **Q. 관심 주제나 전공 관련 수집할 자료가 떠오르지 않으면 어떻게 하나요?**  
  - 수업 현장에서 제공하는 예시 주제 리스트(요리, 기업 신기술 동향 등) 중 하나를 선택해 시작하시면 됩니다.
* **Q. 코딩 경험이 전혀 없는데 따라갈 수 있나요?**  
  - 네! 직접 코드를 짜지 않고 AI 명령어(프롬프트)와 템플릿을 활용하므로 누구나 끝까지 완성할 수 있습니다.
* **Q. 터미널이나 명령어를 써야 하나요?**  
  - 아닙니다. Claude 데스크톱 앱 안에서 한국어로 부탁하면 됩니다. Node.js나 Python도 필요 없습니다.
* **Q. Obsidian 플러그인은 설치해야 하나요?**  
  - 오늘 실습에는 필요 없습니다. 여유가 되면 Dataview, Templater, Omnisearch 정도가 도움이 됩니다.
